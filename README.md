# PoE 필터 편집기

Path of Exile 1 의 **NeverSink 계열 아이템 필터**를 한국어로 보고, 티어·사운드·스택을 바로 고치는 Windows 프로그램이에요.

## 받기

👉 **[최신 버전 받기 (Releases)](../../releases/latest)** — `PoE-Filter-Editor.exe` 하나만 받으면 돼요.

- 설치할 것 없음 (Python·ffmpeg 등 필요한 것이 exe 안에 다 들어 있어요)
- 새 버전이 나오면 앱이 알려주고 버튼 하나로 업데이트돼요
- 바탕화면·문서 폴더처럼 **내 폴더**에 두고 실행하세요 (Program Files 는 업데이트가 막혀요)
- 처음 실행 때 "Windows의 PC 보호"가 뜨면 **추가 정보 → 실행**

## 할 수 있는 것

- **보기**: 분류별 / 아이템별 / 사운드별 / 원본 목차순, 아이템 이름 한글 표시, 게임 라벨 색 미리보기
- **검색**: 아이템을 찾으면 게임이 검사하는 순서대로 "조건 → 티어"를 보여줘요
- **고치기**: 아이템 티어 옮기기·새 티어 만들기, 표시/숨김, 스택 개수, 사운드 변경(눌러서 미리듣기), 같은 사운드 한꺼번에 바꾸기
- **사운드 만들기**: 내 음악 파일이나 유튜브 주소에서 구간을 잘라 필터 알림음(mp3)으로
- **안전한 저장**: 항상 새 이름의 새 파일로 저장 — 원본 필터는 건드리지 않아요

자세한 사용법은 각 릴리스의 `PoE-Filter-Editor-Usage-Guide.txt` 를 보세요.

## 안내

- 이 프로그램은 Grinding Gear Games 와 관계없는 팬 제작 도구예요.
- 아이콘(신성한 오브) 등 게임 이미지의 저작권은 Grinding Gear Games 에 있어요.
- 아이템 한글 이름은 [poedb.tw](https://poedb.tw/kr/) 를 참고했어요.
